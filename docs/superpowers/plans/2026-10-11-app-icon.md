# LiveUse App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the LiveUse app icon with a cyan pointer held by an amber spark, and use a black template of that drawing in the menu bar.

**Architecture:** `icon.svg` is the source for the bundled app icon. `pnpm tauri icon` rasterizes it into the files `tauri.conf.json` already lists. `tray.svg` is a separate black mask; ImageMagick rasterizes it to `trayTemplate.png`, which `install_tray` loads with `icon_as_template(true)`. A Rust test reads both rasters and rejects the old art.

**Tech Stack:** Tauri 2 icon CLI (`pnpm tauri icon`), ImageMagick (`magick`), Rust tests using the existing `image` 0.25 crate.

## Global Constraints

- App icon source is `desktop/src-tauri/icons/icon.svg`, viewBox `0 0 128 128`.
- Plate: rounded rect covering the viewBox, `rx="28"`, fill `#111111`.
- Pointer: `M26 18 L26 84 L44 66 L58 94 L68 89 L54 61 L78 61 Z`, fill `#3EE0E8`, stroke `#071316`, stroke-width `4`, stroke-linejoin `round`.
- Spark translated to `(52, 98)`. Outer fill `#F5B429`: `0,-18 3.2,-3.2 18,0 3.2,3.2 0,18 -3.2,3.2 -18,0 -3.2,-3.2`. Inner fill `#FFF4CC`: `0,-8 1.6,-1.6 8,0 1.6,1.6 0,8 -1.6,1.6 -8,0 -1.6,-1.6`.
- Generate the bundle with `pnpm tauri icon src-tauri/icons/icon.svg` from `desktop/`. No `--png` flag. No iOS color flag.
- Leave the `bundle.icon` array in `desktop/src-tauri/tauri.conf.json` unchanged.
- Menu bar source is `desktop/src-tauri/icons/tray.svg`. Embedded raster is `desktop/src-tauri/icons/trayTemplate.png`, 32×32 RGBA.
- Tray shapes are RGB `0,0,0`. Alpha carries coverage. No plate, no cyan, no amber, no light core. At least 4px of transparent padding on every side.
- Tray pointer, in an 18×18 space: `M3 1.5 L3 12.5 L6 9.5 L8.2 14 L10 13.1 L7.8 8.6 L11.5 8.6 Z`.
- Tray spark, in that same space: `12.2,11.2 12.7,12.6 14.2,13.1 12.7,13.6 12.2,15 11.7,13.6 10.2,13.1 11.7,12.6`.
- That 18×18 drawing is centered in the 32×32 canvas.
- Do not point `pnpm tauri icon` at `tray.svg`. The command must leave `icon.svg` and `tray.svg` in place.
- `install_tray` loads `trayTemplate.png` and calls `icon_as_template(true)`. Menu items and handlers stay as they are.
- Do not change firmware, the in-window title, or the product name.
- No separate Windows tray drawing.

## File structure

- `desktop/src-tauri/icons/icon.svg` — editable color icon. Input to `tauri icon`.
- `desktop/src-tauri/icons/32x32.png`, `128x128.png`, `128x128@2x.png`, `icon.png`, `icon.icns`, `icon.ico`, `Square*Logo.png`, `StoreLogo.png` — outputs of `tauri icon`. The app bundle already points at the first five.
- `desktop/src-tauri/icons/tray.svg` — editable menu-bar mask.
- `desktop/src-tauri/icons/trayTemplate.png` — 32×32 raster embedded by `include_bytes!`.
- `desktop/src-tauri/src/icon_art.rs` — tests only. Not part of the running app.
- `desktop/src-tauri/src/lib.rs` — declares the test module, and `install_tray` switches the tray image.

use std::path::PathBuf;

fn icons_dir() -> PathBuf {
    PathBuf::from(env!("CARGO_MANIFEST_DIR")).join("icons")
}

fn count_near(img: &image::RgbaImage, rgb: [u8; 3], tol: u8) -> usize {
    img.pixels()
        .filter(|px| {
            px.0[3] > 200
                && px.0[..3]
                    .iter()
                    .zip(rgb)
                    .all(|(channel, expected)| channel.abs_diff(expected) <= tol)
        })
        .count()
}

#[test]
fn app_icon_matches_the_spark_mark() {
    let svg = std::fs::read_to_string(icons_dir().join("icon.svg")).expect("read icon.svg");
    assert!(svg.contains(r#"M26 18 L26 84 L44 66 L58 94 L68 89 L54 61 L78 61 Z"#));
    assert!(svg.contains(r#"fill="#3EE0E8""#));
    assert!(svg.contains(r#"fill="#F5B429""#));
    assert!(svg.contains(r#"fill="#FFF4CC""#));
    assert!(svg.contains(r#"fill="#111111""#));

    let img = image::open(icons_dir().join("32x32.png"))
        .expect("open 32x32.png")
        .to_rgba8();
    assert_eq!(img.dimensions(), (32, 32));
    let plate = count_near(&img, [0x11, 0x11, 0x11], 8);
    let cyan = count_near(&img, [0x3E, 0xE0, 0xE8], 40);
    let amber = count_near(&img, [0xF5, 0xB4, 0x29], 40);
    assert!(plate > 200, "plate pixels {plate}");
    assert!(cyan > 10, "cyan pixels {cyan}");
    assert!(amber > 5, "amber pixels {amber}");
}
```

Tauri 2.12.1's antialiased `32x32.png` has 6 pixels within tolerance of `#F5B429`. The acceptance criterion is that raster, not a sharper replacement. `amber > 5` locks it. `plate > 200` is what rejects the old icon.

#[test]
fn tray_template_is_a_black_mask() {
    let svg = std::fs::read_to_string(icons_dir().join("tray.svg")).expect("read tray.svg");
    assert!(svg.contains(r#"M3 1.5 L3 12.5 L6 9.5 L8.2 14 L10 13.1 L7.8 8.6 L11.5 8.6 Z"#));
    assert!(svg.contains("12.2,11.2 12.7,12.6 14.2,13.1 12.7,13.6 12.2,15 11.7,13.6 10.2,13.1 11.7,12.6"));
    assert!(!svg.to_ascii_lowercase().contains("#3ee0e8"));
    assert!(!svg.to_ascii_lowercase().contains("#f5b429"));

    let img = image::open(icons_dir().join("trayTemplate.png"))
        .expect("open trayTemplate.png")
        .to_rgba8();
    assert_eq!(img.dimensions(), (32, 32));

    let mut ink = 0usize;
    for (x, y, px) in img.enumerate_pixels() {
        let edge = x < 4 || y < 4 || x >= 28 || y >= 28;
        if edge {
            assert_eq!(px.0[3], 0, "padding at {x},{y}");
        }
        if px.0[3] > 200 {
            assert!(
                px.0[0] <= 8 && px.0[1] <= 8 && px.0[2] <= 8,
                "colored pixel at {x},{y}: {:?}",
                px.0
            );
            ink += 1;
        }
    }
    assert!(ink > 10, "ink pixels {ink}");
}
```
